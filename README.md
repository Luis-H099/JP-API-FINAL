# JP-API

Este repositório reúne a evolução do projeto JP-API.

## Versão final

A versão final e principal do projeto é a **JP-API-4**, mantida na raiz deste repositório.

## Versões anteriores

As versões anteriores foram preservadas na pasta `Versoes-antigas`:

- `JP-API-1/` — primeira versão do projeto.
- `JP-API-2/` — segunda versão, com melhorias em relação à inicial.
- `JP-API-3/` — versão intermediária que introduziu funcionalidades adicionais, incluindo consulta de CEP.

Essas pastas servem como histórico de desenvolvimento. A versão principal é a JP-API-4.

## Tecnologias

- C#
- ASP.NET Core Web API
- SQL Server
- Dapper

O código da versão final foi mantido separado das versões anteriores. Os arquivos históricos foram copiados sem alterar a implementação da JP-API-4.
